# Digiteq brand assets

Transparent PNG exports from the Digiteq logo suite.

| File | Source | Use |
|------|--------|-----|
| `lockup.png` | Color D + DIGITEQ (stacked) | Nav / footer / register surfaces |
| `lockup-mono.png` | Mono D + DIGITEQ (stacked) | Dark / vault surfaces |
| `icon.png` | Icon-only pixel D (square) | Compact mark, JSON-LD |
| `emblem.png` | Icon-only D (tight crop) | Standalone mark |
| `wordmark.png` | Same as color lockup | Alternate lockup path |
| `hero-3d.png` | Color lockup | Hero / large placements |
| `og.png` | Color lockup on vault field | Open Graph 1200×630 |
| `favicon-32.png` / `icon-192.png` / `icon-512.png` | Icon-only D | PWA / favicon helpers |

**Favicon rule:** use the icon-only mark (`icon.png` / App Router icons), never the full lockup.

App Router icons live in `app/icon.png`, `app/apple-icon.png`, and `app/favicon.ico` (all derived from the icon-only asset).
